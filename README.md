# 📚 مشروع مكتبة الكتب (Bookstore Laravel Project)

## 🧩 نظرة عامة
مشروع **مكتبة الكتب** هو تطبيق ويب متكامل مبني باستخدام **Laravel** لإدارة وبيع الكتب عبر الإنترنت.  
يوفّر النظام **واجهة مستخدم عامة** لتصفح الكتب والبحث عنها وتقييمها وإضافتها إلى سلة المشتريات، بالإضافة إلى **لوحة تحكم إدارية** لإدارة جميع مكونات المتجر مثل الكتب، المؤلفين، الناشرين، التصنيفات، والمستخدمين.

يهدف المشروع إلى تقديم تجربة تسوق إلكترونية حديثة وسهلة لعشاق الكتب، مع نظام مصادقة وصلاحيات متكامل وواجهة مستخدم متجاوبة.

---

## ⚙️ الخصائص الأساسية

### 🛍️ واجهة المستخدم
- تصفح جميع الكتب المتاحة في المتجر.  
- البحث الذكي عن الكتب حسب العنوان، المؤلف، التصنيف، أو الناشر.  
- عرض تفاصيل الكتاب (الوصف، المؤلف، الناشر، التقييمات).  
- إمكانية تقييم الكتب من قبل المستخدمين المسجلين.  
- عرض تصنيفات الكتب، المؤلفين، والناشرين بشكل مستقل.

### 🛒 سلة المشتريات والدفع
- إضافة وإزالة الكتب من سلة المشتريات.  
- عرض محتويات السلة وإدارة الكميات قبل إتمام الشراء.  
- دعم الدفع عبر:
  - 💳 بطاقة الائتمان  
  - 💰 PayPal (متكامل عبر واجهة API)  
- إرسال بريد إلكتروني تلقائي للمستخدم بعد إتمام عملية الشراء يحتوي على تفاصيل الطلب (`OrderMail`).

### 🧑‍💼 لوحة الإدارة
- الوصول عبر `/admin`، محمية بنظام صلاحيات المستخدمين.  
- إدارة شاملة للكتب، التصنيفات، المؤلفين، الناشرين، والمستخدمين.  
- عرض إحصائيات عامة في لوحة التحكم (عدد الكتب، التصنيفات، المؤلفين، الناشرين).  
- واجهات CRUD كاملة لجميع المكونات.

---

## 🗂️ المكونات الأساسية

### 📘 النماذج (Models)
- `Book` – إدارة بيانات الكتب.  
- `Author` – إدارة بيانات المؤلفين.  
- `Publisher` – إدارة بيانات الناشرين.  
- `Category` – إدارة تصنيفات الكتب.  
- `Rating` – إدارة تقييمات المستخدمين.  
- `Shopping` – تمثيل عناصر السلة وعمليات الشراء.  
- `User` – إدارة المستخدمين مع صلاحيات كاملة.

### 🎮 الكنترولات (Controllers)
- `GalleryController` – عرض الصفحة الرئيسية ومعرض الكتب.  
- `BooksController` – إدارة الكتب وتفاصيلها والتقييم.  
- `CartController` – إدارة السلة وإزالة العناصر.  
- `PurchaseController` – إدارة عمليات الشراء (بطاقة ائتمان / PayPal).  
- `CategoriesController`, `AuthorsController`, `PublishersController` – عرض القوائم والتفاصيل.  
- `AdminsController` – لوحة الإدارة والإحصائيات.  
- `UsersController` – إدارة المستخدمين وصلاحياتهم.

---

## 🔐 المصادقة والصلاحيات
- حماية المسارات باستخدام **middleware** مثل `can:update-books` و`can:update-users`.  
- يعتمد المشروع على **Jetstream** لتوفير تسجيل الدخول والتسجيل والتحقق من البريد الإلكتروني وإدارة الحسابات.  
- جميع مسارات الإدارة تبدأ بـ `/admin` وتتطلب صلاحيات محددة.

---

## 💬 البريد الإلكتروني
- إرسال بريد إلكتروني تلقائي بعد إتمام عملية الشراء يحتوي على تفاصيل الطلب.  
- قوالب البريد موجودة في:  
  `resources/views/mails/order-mail.blade.php`

---

## 🧰 التقنيات المستخدمة
- **Laravel** 10.x  
- **Jetstream** (نظام المصادقة وإدارة الحسابات)  
- **Blade Templates** (واجهة المستخدم)  
- **MySQL / Eloquent ORM**  
- **PayPal API** و **Credit Card Checkout**  
- **Mailables** لإرسال البريد الإلكتروني  
- **Vite + Node.js** (لتجميع ملفات CSS وJS مثل Tailwind أو Bootstrap)

## 🚀 متطلبات التشغيل

### 🔧 المتطلبات
- PHP >= 8.1  
- Composer  
- MySQL  
- Node.js >= 18  
- NPM (مرفق مع Node.js)  
- مفاتيح PayPal API (اختياري)

### ⚙️ خطوات التشغيل محليًا
```bash
# 1. تثبيت اعتماديات PHP
composer install

# 2. تثبيت اعتماديات الواجهة (Node)
npm install

# 3. إعداد ملف البيئة
cp .env.example .env
php artisan key:generate

# 4. إنشاء قاعدة البيانات والجداول
php artisan migrate --seed

# 5. بناء ملفات الواجهة
npm run dev   # للتطوير
# أو
npm run build # للإصدار النهائي

# 6. تشغيل الخادم المحلي
php artisan serve
